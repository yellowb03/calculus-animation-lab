# Real-time Calculus Animation Lab

User revision: deliver a local interactive web app INSTEAD of rendering videos. Existing 12 textbook-grounded lesson scripts are authoritative. Their mathematical answers were independently checked. Preserve previous files; write new app only here. App works by double-clicking index.html, without a server or network, using local classic scripts and bundled KaTeX/math.js/fonts.

## Intended experience and settled design

Pinned user visual style: black stage, one large white LaTeX equation, cyan inserted factors, red cancellation focus, short explanation on right. Live Cartesian curve under equation; visible objects move in response to current operation. User can select homework, go Back/Next, play/pause, scrub the current operation, replay it, adjust speed, inspect a curve, zoom/reset, optionally hear browser speech. No video files or canvas-to-video render required. New typed problems supported where reliable; unsupported symbolic work must be identified, never fabricate an explanation. Any authored problem can use imported step JSON and function-graph schema.

Desktop composition: slim header, collapsible homework list ~240px, spacious black workstage, one equation upper center (~52-72px when room, fit at minimum28px), graph below with axes/numeric ticks, explanation right~300px. Bottom transport stays within view. Mobile stacks explanation and graph and provides a compact lesson selector; equations horizontally scroll as last resort rather than clipped. Neutral humanist sans UI with local font, KaTeX math. No decorative gradients or ornamental cards. Keyboard left/right=step, space=play (except form fields); visible focus. Reduced motion supported, live graph meaningful even when paused (manual slider).

## Shared contract (classic browser globals)

Load order vendor/math.js, vendor/katex/katex.min.js, lessons.js, graphs.js, solver.js, app.js.

window.CALCULUS_LESSONS is array of original JSON lessons (id,title,homework,section,exercise,textbook_page,problem,source_note,steps). Step fields title,why,narration,parts:[{id,tex,color white/cyan/red}], optional hold. Optional graph metadata on any lesson.

window.CalculusGraphs.draw(canvas,lesson,stepIndex,progress,view={}) draws live Cartesian scene. stepIndex ZERO-BASED, progress0..1. view={zoom:1,panX:0,panY:0,inspectX:null}. Return {bounds:{xMin,xMax,yMin,yMax},pixelToWorld(px,py),worldToPixel(x,y)} using CSS pixel coordinates. Canvas scales for devicePixelRatio; draw is called on requestAnimationFrame and must stay lightweight. Graph title/cue must explain what is shown, no false secondary big equation. Original 12 map by lesson.id two-digit prefix. Dynamic lesson.graph = {kind:'function',expression,variable:'x',base:1,xRange:[-3,3],yRange:optional,tangent:true,derivative:optional string,holes:optional [{x,y}],limitTarget:optional number}; compile safely through math.js cached validated expressions.

window.CalculusSolver.buildLesson({mode:'derivative'|'tangent'|'linearization'|'limit',expression,variable:'x',at:'1'}) returns a lesson with graph config and meaningful algebraic steps or throws an Error with clear recovery. Synchronous for bounded inputs. window.CalculusSolver.examples array optional. No JS eval/new Function, no network. Restrict math.js AST to scalar operations and known elementary functions, numeric constants, selected variable, pi/e. Bound input length, exponent size, node count, recursion; return controlled error for unsupported nodes/functions. No arbitrary assignments/imports/accessor/arrays. Custom solver fidelity takes priority over category count.
