# Visual and interaction direction

Preserve the user's explicit black/white/cyan/red mathematical teaching stage. The equation is the display voice (KaTeX Computer Modern); the rest of the UI recedes. One live graph gives each transformation a spatial meaning. Controls resemble a mathematical instrument: concise labels, visible keyboard focus, clear transport, direct manipulation via current-step progress slider.

Mode: Operate/Read. Desktop equation and graph left, concise explanation right, compact homework navigation. Mobile stacks these without losing equation content or transport. Local humanist sans font for prose, subdued neutral axis/secondary text, no decorative background. Mathematical accuracy and discoverable backward/forward behavior outrank surface novelty. Respect reduced motion.
